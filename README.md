# Portfolio — E. William Harris IV

Source for William's personal portfolio page, served with GitHub Pages at
https://grateful-ed.github.io/portfolio/

Plain static HTML and CSS — no build step, no frameworks. `index.html` is the
page, `style.css` is the notebook styling (light paper, plus a dark "night
notebook" under `prefers-color-scheme`), and `images/` holds the project
screenshots.

This repository stands alone: it is not part of Ship Safe, Witness, or the
TMS Consolidation Agent repos — it only links out to them.
