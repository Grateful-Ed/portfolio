TMS Consolidation Agent

Freight consolidation that proposes and asks — deterministic numbers, plainly phrased, with the struggle left visible.

Open the live demo Read the code in its own words On GitHub

Freight consolidation done by hand is a phone, a spreadsheet, and a planner’s memory of which carriers forgive what. This agent reads the week’s shipments, works out which ones can ride together, and prices the saving — but every number on the page is computed by a deterministic engine, not by the model. The model’s job is only to phrase what the engine decided, in the planner’s own words where it matters.

It proposes and asks. Nothing is booked, tendered, or made official by the tool; a planner accepts or rejects each move. And where a consolidation does not fully work — a shipment that still lands alone, a saving that leaves a residue behind — the struggle is shown on the page, not absorbed into the total. A tool that hides its hard cases teaches its planner to stop checking it.
