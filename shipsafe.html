Ship Safe

A dangerous-goods pre-screening desk for freight forwarders: it reads the commercial document, works every line against the rulebooks, and hands a screener a determination — never a sign-off.

Open the live demo Read the build journal

An air export agent reads a stack of commercial documents and works out, line by line, whether each one is acceptable for the flight. That used to eat the first hour or two of my day, every day — and the working lives at the start of a career are spent there, on mountains of paperwork, before anyone is trusted with the interesting problems. I built Ship Safe to give that time back. It is a pre-screening desk: it reads the document, works each line against the rulebooks, and calls what it finds.

It pulls the shipment lines off the paperwork and identifies each product as specifically as the document allows — because dangerous-goods rules attach to exact identities, not to rough descriptions. It then derives each line from the law itself: the UN number and 49 CFR carry the classification; carrier and operator rules come after; a tariff code is context only and never classifies anything. Where the document alone cannot identify a line, Ship Safe says so and asks, instead of guessing.

Development ran on synthetic test documents, written from real commercial paperwork patterns with the identifying details changed — never on a real customer’s freight. The demo below runs a built-in sample shipment.

The principles it is built on

The machine never signs off. A person does.

A shipper’s declaration governs. A UN number or class stated on the document is a hard block, not a hint.

When the evidence runs out, the tool asks. It does not improvise an identity for a product.

Second looks are labeled as second looks. Nothing advisory ever presents itself as the screening.
